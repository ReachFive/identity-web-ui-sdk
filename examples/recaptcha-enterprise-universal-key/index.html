reCAPTCHA Enterprise — Universal key

A Universal key unlocks the Policy Engine: CEL rules decide deterministically whether to challenge a user, instead of handing back a score for you to threshold. The browser integration is identical to the score-based key — same script, same grecaptcha.enterprise.execute(), same captcha_token. This page runs the very same SDK options as the web-key demo; everything that differs lives in Google Cloud and in the ReachFive client configuration.

Pin an action. ReachFive requires an expected action to be configured per endpoint for Universal keys, because Policy Engine rules are written against the action name. With no action pinned, rules that match on it cannot fire.

What to watch for

Submit the form with a policy rule configured to challenge. The challenge is rendered by execute() itself, so the promise settles only once the user has dealt with it — the log stays silent in between, and no request is sent until then. If the user dismisses the challenge, execute() rejects and the widget reports the SDK's generic recaptcha.error message; that is worth keeping in mind when writing copy for a Universal-key deployment, since the same message covers "Google is unreachable" and "you closed the challenge".
