reCAPTCHA Enterprise — score-based web key

The default Enterprise integration. The SDK mints a token with grecaptcha.enterprise.execute() and posts it as captcha_token; ReachFive creates an assessment and compares the returned score against the threshold configured on the client. A challenge is never shown — the score is the only signal.

What went over the wire

ReachFive configuration

In the console, under the client's reCAPTCHA Enterprise configuration, set the Google Cloud project ID, this site key, a credential (API key or service account) and a threshold, and enable the endpoints you want protected. Pinning an action per endpoint is optional here — when it is left unset, ReachFive enforces the expected action itself.
